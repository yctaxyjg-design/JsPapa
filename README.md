# JsPapa

## 국기 맞히기 놀이 (`flag-game/`)

6세 아이를 위한 나라 국기 퀴즈 게임입니다. 국기를 보여주면 아이가 **말로** 나라 이름을 맞히고, 정답이면 그 나라의 특징·수도·역사 이야기를 음성으로 읽어줍니다.

- 음성 인식(Web Speech API, 한국어)으로 정답 판정 — 마이크가 안 되는 환경에서는 3지선다 버튼으로 대답
- 정답 시 색종이 축하 효과 + TTS로 나라 정보 낭독
- 한 번에 맞힌 문제마다 별점 ⭐, 10문제 한 판
- 아이패드 사파리에 최적화 (홈 화면에 추가하면 전체 화면 앱처럼 사용 가능)

`flag-game/index.html`을 아이패드 사파리로 열면 됩니다. 음성 인식은 보안 정책상 `https://` 또는 로컬 서버에서 열어야 동작합니다 (GitHub Pages 배포 추천).

## 🎨 국기 색칠 놀이 (`flag-color/`)

6세 아이를 위한 나라 국기 **색칠 게임**입니다. 색을 고른 뒤 빈 국기 틀을 톡톡 눌러 색을 채워요.
색칠 그림책처럼 옆에 정답 국기를 "이렇게 색칠해요"로 보여줘 따라 칠하며 국기를 익힙니다.

- 팔레트에서 색을 탭 → 국기 빈 칸을 탭해서 채우기 (색을 다시 골라 탭하면 고쳐짐)
- 모든 칸을 채우면 자동 채점 — 맞으면 색종이 축하 + 소리 + TTS로 나라 이야기 낭독, 틀려도 벌 없이 "다시 볼까요?"
- 삼색기 위주 쉬운 국기 9개(프랑스·이탈리아·독일·네덜란드·일본·스웨덴·아일랜드·벨기에·나이지리아), 별점·진행도
- 인라인 SVG로 그린 국기라 외부 이미지·CDN 의존이 전혀 없고, 아이패드 사파리 가로/세로에 맞춰 반응형

`flag-color/index.html`을 브라우저로 열면 됩니다. (마이크·네트워크 없이 오프라인에서도 동작)

## 👪 육아 공평분담 스프레드시트 (`parenting/`)

아빠·엄마가 **함께 쓰는** 육아 분담 기록 PWA. 매일 10개 육아 항목에서 담당한 사람을 탭하면
누적 담당 횟수·육아일 환산 격차·취침 격차·이번 달 분담률이 실시간으로 계산됩니다.
iCloud Drive 백업 파일로 두 사람의 기록을 셀 단위 병합합니다. 자세한 내용은
[`parenting/README.md`](parenting/README.md).

## 🎨 수학놀이터 (`math-play/`)

애플펜슬로 쓰고 긋고 나누며 **수 개념의 원리**를 배우는 6세용 아이패드 웹앱.
직산(subitizing)·수 가르기(number bond)·십틀(ten frame)·공평 분배 등 검증된 수학 교육 이론 기반의 미니게임 5종과
$P 알고리즘 손글씨 숫자 인식기를 담고 있습니다. 자세한 내용은 [`math-play/README.md`](math-play/README.md).

## 🗂️ 옵시디언 볼트 정리기 (`obsidian/`)

옵시디언 볼트(마크다운 폴더)를 **브라우저에서 열어** 태그·백링크·고아 노트·깨진 링크를 살펴보고,
볼트에 다시 넣을 **정리 리포트(.md)** 를 만드는 정적 웹앱. 노트는 업로드 없이 브라우저 안에서만
분석합니다. 자세한 내용은 [`obsidian/README.md`](obsidian/README.md).

## 🧭 AI 워크플로 스캔 (`ai-workflow/`)

AI 도구(Claude Code·Codex/ChatGPT·Gemini·Ollama 등)의 주간 변화를 훑고 **이번 주에 실제로 시험해볼 것만**
우선순위·시험 절차·합격 기준까지 정해 남기는 실행 대기열. 주장마다 검증상태(`확인`/`제공`/`추론`)를 붙여
원문 대조를 한 것과 안 한 것을 섞지 않습니다. 자세한 내용은 [`ai-workflow/README.md`](ai-workflow/README.md).

## iPad 전원 스케줄러

iPad의 전원을 시간대별로 켜고/끄는 일정을 관리하고, 그 일정을 iOS 단축어(Shortcuts) 오토메이션으로 설정하는 방법을 안내해주는 정적 웹앱입니다.

## 한계

iPadOS는 보안·전력 관리 정책상 **서드파티 앱이 기기의 전원을 직접 켜거나 끌 수 없습니다.** 따라서 이 앱은 다음과 같은 우회 자동화를 도와줍니다.

- 화면 잠금 / 깨우기
- 집중 모드(Focus) 전환
- 저전력 모드 전환
- 무음 / 볼륨 조절

## 사용법

1. `index.html`을 브라우저로 엽니다 (또는 GitHub Pages에 배포).
2. "일정 추가" 폼에서 이름, 동작, 시간, 요일을 입력합니다.
3. 등록된 일정 목록 아래에 단축어 앱 자동화 설정 가이드가 표시됩니다.
4. iPad의 단축어 앱에서 가이드대로 오토메이션을 등록하세요.

## 데이터

일정은 브라우저의 `localStorage`에만 저장됩니다. JSON으로 내보내기/가져오기가 가능합니다.
