# AI 워크플로 스캔 (`ai-workflow/`)

매주 AI 도구(Claude Code·Codex/ChatGPT·Gemini·Ollama 등)의 변화를 훑고, **이번 주에 실제로 시험해볼 것만** 골라 남기는 기록.

읽을거리 요약이 아니라 **실행 대기열**이다. 각 항목은 시험 절차·합격 기준·중단 조건까지 적고, 다음 주 스캔에서 결과를 회수한다.

## 구조

```
ai-workflow/
  scan/YYYY-MM-DD.md          주간 스캔 (우선순위표 + 실험별 시험 절차)
  실무노트_추가후보_AI-NN.md   스캔에서 확정된 재사용 가능한 원칙
```

## 검증상태 표기

`ftedit/crosscheck/`, `scripts/tax/실무노트_추가후보_*.md`와 같은 규율을 쓴다. 주장마다 출처 등급을 붙여, 원문 대조를 한 것과 안 한 것을 섞지 않는다.

| 표기 | 뜻 |
|---|---|
| `확인` / `저장소확인` | 이 저장소에서 직접 확인 (파일·설정 실측) |
| `제공` / `미검증` | 외부 릴리스·문서 내용. 원문 대조 안 함 — 실행 전 확인 필요 |
| `추론` | 근거에서 끌어낸 판단이지 발표된 사실이 아님 |
| `정정` | 이전 스캔의 판단을 뒤집은 것 |

버전 번호·성능 수치·기능 범위는 기본이 `제공`이다. 실행하면서 사실과 달랐던 항목은 다음 주 스캔에 `정정`으로 올린다.

## 현재 기준선 — AI 멀티워크플로 표준

| 층 | 원칙 |
|---|---|
| 구성 | Single Source → Agent Import/Sync (에이전트별 설정 복제 금지) |
| 병렬 판단 | Shared-Prefix Cache (비싼 클라우드 agent는 cache 태워 병렬) |
| 반복·검증가능 처리 | Local-first (로컬 모델로 내림) |
| ambient memory | allowlist only (include-only, 예측 불가 앱 제외) |
