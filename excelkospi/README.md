# 📊 스프레드시트 시세판 (`excelkospi/`)

국내 주식·지수·코인 시세를 **스프레드시트 화면 그대로** 보는 정적 웹앱.
리본·수식 입력줄·시트 탭·상태 표시줄까지 흉내 내서, 창을 하나 띄워 두면 표 작업 중인 화면처럼 보입니다.
`excelkospi.pages.dev`가 하는 일을 이 저장소 규칙(빌드 도구·외부 CDN 없음)에 맞춰 다시 만든 것입니다.

`excelkospi/index.html`을 브라우저로 열면 됩니다. 설치·빌드 과정은 없습니다.

## 화면

| 시트 탭 | 실제 내용 |
| --- | --- |
| `실적_국내` | 관심 종목·지수 시세 (단가=현재가, 증감/증감율, 수량=거래량, 금액=거래대금) |
| `실적_해외` | 코인 시세 (업비트 원화 마켓) |
| `원가집계` | 보유 수량·취득단가로 계산한 평가금액·평가손익 |
| `Sheet1` | 사용법 메모 |

- 셀을 클릭하면 이름 상자와 수식 입력줄이 바뀌고, Shift+클릭·Shift+방향키로 범위를 잡으면
  상태 표시줄에 평균·개수·합계가 나옵니다.
- 상승은 빨강, 하락은 파랑(국내 관행). 데이터가 모의값이면 흐리게 표시하고 비고 열에 `데모`라고 적습니다.

## 화면 보호(위장)

- **Esc** 또는 **`** 키 → 「부서별 예산 집행 현황」 표로 즉시 전환. 같은 키로 복귀합니다.
- 상태 표시줄 왼쪽의 **"준비"** 를 눌러도 전환됩니다.
- `[보기] → 창 벗어나면 화면 보호`를 켜면 다른 창을 클릭하거나 탭을 벗어날 때 자동으로 전환됩니다.
  (복귀는 항상 수동입니다.)

## 데이터 연결

| 대상 | 소스 | 필요한 것 |
| --- | --- | --- |
| 코인 | 업비트 공개 시세 API | 없음 (바로 붙습니다) |
| 국내 주식 | 공공데이터포털 「금융위원회_주식시세정보」 | 인증키 |
| 지수(코스피·코스닥) | 공공데이터포털 「금융위원회_지수시세정보」 | 인증키 |

`[데이터] → [연결 속성]`에 인증키를 넣으세요. 키는 **이 브라우저의 localStorage에만** 저장되며
서버로 보내지 않습니다. 공공데이터포털 API는 **전 영업일 종가** 기준이라 장중 실시간 값이 아니고,
비고 열에 `08/19 종가`처럼 기준일이 표시됩니다.

어떤 소스든 실패하면(키 없음, 사내망 차단, CORS 거부) 조용히 **모의 시세**로 떨어져 화면만 유지합니다.
상태 표시줄에 `연결됨` / `연결됨 8/15` / `데모 데이터`로 상태가 나옵니다.
브라우저에서 공공데이터 API를 직접 부르지 못하는 환경이면 `[연결 속성]`의 **프록시 주소**에
`https://…` 앞부분을 넣으세요. 그 뒤에 `/1160100/service/…` 경로를 붙여 호출합니다.

## 저장

관심 항목·보유 수량·설정은 `localStorage`(키 `excelkospi.v1`)에만 저장됩니다. 계정도 서버도 없습니다.

## 만든 방식

- 빌드 도구·프레임워크·외부 폰트/CDN 없음. 순수 HTML/CSS/바닐라 JS.
- `quotes.js` 시세 소스, `sheets.js` 시트(셀 맵) 정의, `app.js` 렌더·이벤트로 나눠 두었습니다.
- 창 너비에 맞춰 빈 열을 채워 격자가 끊기지 않게 하고, 확대/축소는 CSS 변수 하나로 처리합니다.

## 유의

투자 판단에 쓰라고 만든 화면이 아닙니다. 시세는 지연·모의값일 수 있고, 근무 중 사용 책임은 각자에게 있습니다.
